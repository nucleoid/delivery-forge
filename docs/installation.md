# Disposable installation

The package is a .NET 10 PackAsTool artifact containing the actual tool and thin skill/reference documentation. No global installation, PATH, agent config, authentication or service is changed by this source slice.

`PackageLifecycle.Install` is the explicit disposable-prefix API: require a new absolute Linux/Windows prefix and independently pinned actual runtime host; inspect complete archive entries with finite count/expanded-byte bounds and reject traversal, aliases, special files, private paths and secrets. Copy only the tool runtime subtree, create a platform shim and retain the exact claim/manifest/receipt outside later caller assumptions. Verify complete file AND directory membership. This custom prefix profile does not assert that `dotnet tool install` has run or that an agent discovered the skill.

CI source prepares a genuine package and SHA before the installed-binary tests. Linux and Windows tests must run the real package; absent actual fixtures fail rather than skip. StandardToolInstallTests additionally defines actual `dotnet tool install --tool-path` from a fresh local-only feed/config, real platform shim invocation, uninstall and separate fresh-prefix reinstall on each OS. These tests are unexecuted. Genuine host skill discovery remains a separate required acceptance gate. macOS is unclaimed.

Source validation is currently unexecuted. New locked assets must be generated by an admitted real restore, reviewed and committed before locked CI can pass. Do not fabricate lock files or weaken locked restore. Installation source is not an installed-outcome certification.
