# Vendored anti-slop provenance

- Upstream: <https://github.com/dmmulroy/anti-slop>
- Pinned commit: `13909c9e07590f5a85d93c62712259fe14a883f7`
- Upstream package version at the pin: `0.1.2` (`private: true`; there is no official npm package)
- License: MIT; the upstream `LICENSE` is retained verbatim as `vendor/anti-slop/LICENSE`.
- Runtime: `oxlint` and `@oxlint/plugins` are both pinned exactly to `1.78.0`; the reviewed upstream development toolchain is pinned to `tsx` `4.23.12` and TypeScript `7.0.2`.

`vendor/anti-slop/` contains the reviewed runtime rule source required by the generic plugin and the separately registered Effect plugin. Upstream tests, skills, scripts, repository configuration, and package-manager metadata are intentionally excluded. The nested ESLint Stylistic license and provenance used by `require-readable-spacing` are retained with that source.

The generic rules are enabled by `oxlint.config.ts`. Effect-specific rules are disabled by default and exist only in `oxlint.effect.config.ts`, which must be selected explicitly by trusted plugin configuration. Delivery Forge never invokes Oxlint autofix and does not rewrite a target repository's lint configuration.

At execution, Delivery Forge derives every tracked JavaScript-family entry from the exact frozen Git tree. Only exact paths in protected-base `.delivery-forge/anti-slop-ignore` may be excluded; patch-head ignore files have no authority. The input identity hashes each path, blob id, mode and include/exclude decision. Non-regular entries fail closed. Bounded `git cat-file --batch-check`/`--batch` groups supply the exact committed bytes, independent of checkout conversion or smudge filters, and those bytes are verified with Git's object hash before linting.

One production linear tokenizer/parser reads complete line and block comment bodies while excluding strings, templates, regular expressions, and prose. It compares normalized semantic coverage multisets between base and head. Inherited coverage and narrower unrelated directives remain valid; new or widened blanket, `anti-slop`, `anti-slop-effect`, or `oxc/no-accumulating-spread` coverage is refused. File, directive-body, directive-count, rule-count, and rule-length caps plus shared byte-based deadline/cancellation checks fail closed to `INCOMPLETE`.

The host registers the installed bundle root and absolute Node executable in trusted code. Direct argv is capped at 24,000 bytes; bundled `run-oxlint-batches.mjs` safely batches larger manifests with argument arrays, no shell, an 8 MiB manifest ceiling, at most 100,000 inputs, 4,096 UTF-8 bytes per input path, bounded batches/diagnostics, aggregate completeness checks, and a shrinking shared deadline. The same bounds are code-owned by the .NET factory and pre-deserialization snapshot path; the reviewed runner is digest-pinned into that closure. The enclosing .NET executor kills the full Node/Oxlint process tree on timeout or cancellation. One pre-execution snapshot asynchronously reads and caches the config, runner, manifest, vendored rules, lockfile, Oxlint JS/native/plugin, Node runtime, and environment closure under the remaining gate deadline. Every enumeration step checks cancellation and every file read receives the deadline-linked token. Later binding and validation reuse the frozen identities instead of re-reading the closure. A missing, malformed, cancelled, or pin-mismatched snapshot persists `INCOMPLETE` before tool execution. The same-UID host does not claim post-snapshot immutability; future-v2 authority remains disabled until a separately privileged host owns these bytes.

`npm run test:fixtures` invokes only the package-local pinned Oxlint binary with ignores and nested target configuration disabled. `npm run test:batch` exercises the code-owned manifest batch host against the same pin. The fixture suite proves clean, policy-violation, malformed-syntax, inline suppression, ASI statement-regex, `for await` regex, byte-zero hashbang, the pinned parser-error behavior for BOM followed by hashbang, the `eslint/no-accumulating-spread` alias for configured `oxc/no-accumulating-spread`, line-comment `*/`, and multiline block-comment newline cases against real Oxlint/plugin execution without global installation. `test-batches.mjs` additionally proves malformed count kinds and non-object diagnostics fail closed through the batch host. CI performs an exact-lock `npm ci` only on the hosted validation worker, then runs all three vendored commands; local remediation validation uses the already-installed package-local pin and performs no install.
